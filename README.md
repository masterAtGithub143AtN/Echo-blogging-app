# Echo Blogging Platform

A modern full-stack blogging platform that enables users to create, publish, and manage blogs with secure authentication and a responsive user interface.

## 🚀 Live Demo

🌐 https://echo-blogging-app-git-main-saket-sumans-projects-057f0dcb.vercel.app/

---

## ✨ Features

- User Registration & Login
- Secure JWT Authentication
- Create, Edit and Delete Blogs
- Rich Blog Publishing
- User Profile Management
- Search Blogs
- Responsive User Interface
- RESTful APIs
- Protected Routes
- Database Integration using PostgreSQL

---

## 💻 Getting Started

### Clone the repository

```bash
git clone https://github.com/<your-username>/Echo-blogging-app.git
```

### Install dependencies

Frontend

```bash
npm install
```

Backend

```bash
npm install
```

### Run the application

Frontend

```bash
npm run dev
```

Backend

```bash
npm run dev
```
